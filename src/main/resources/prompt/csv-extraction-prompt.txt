=== CSV-SPECIFIC HANDLING ===

Column Header Normalization:
- Treat "camelCase", "snake_case", "Title Case", "UPPER CASE" as equivalent when matching patterns
- Extract the original header name as-is for technicalImplementation or schemaDefinition

Empty Cells:
- Empty/blank cells → omit the field from JSON
- "N/A", "TBD", "TODO", "Unknown" → omit or set confidence to 0.5

Multi-Value Cells:
- "Value1, Value2, Value3" → parse as array ["Value1", "Value2", "Value3"]
- "Value1; Value2" → parse as array (semicolon delimiter)
- "Value1 | Value2" → parse as array (pipe delimiter)

Conditional Logic in Cells:
- "If X then Y" → extract as businessRule with condition="X" and outcome="Y"
- "When X, do Y" → extract as workflow step or businessRule
- "X must be Y" → extract as businessRule with ruleType="validation"

Formula Cells:
- "=SUM(A1:A10)" → extract formula in technicalImplementation field
- Describe formula purpose in calculationMethod for metrics

Special Rows:
- Skip header rows (usually row 1 unless data starts later)
- Skip footer rows with totals/summaries unless they define metrics
- Skip comment rows (starting with #, //, etc.)

=== CONFIDENCE SCORING FOR CSV DATA ===

High Confidence (0.9-1.0):
- Data explicitly present in cells with clear headers
- Direct mappings with both source and target populated
- Rules with complete condition and outcome
- Well-defined data models with field names and types

Medium Confidence (0.7-0.89):
- Data present but header name is ambiguous
- Partial mappings (source present, target inferred from context)
- Rules with condition but no explicit outcome
- Field definitions missing data types

Low Confidence (0.5-0.69):
- Inferred from surrounding cells or row context
- Ambiguous cell values (e.g., abbreviations without legend)
- Relationships implied by column position, not explicit
- Missing or "TBD" values where business meaning is guessed

Omit Entirely (confidence < 0.5):
- Pure speculation not supported by CSV data
- Empty cells or placeholder values
- Cannot determine entity type from context
